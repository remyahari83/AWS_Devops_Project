Step 1 — Create Argo CD namespace
kubectl create namespace argocd
If it says AlreadyExists, ignore.

Step 2 — Install Argo CD
Use the official stable manifest:
kubectl apply -n argocd \
  -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

Ignore applicationsets.argoproj.io annotation warning again. That's okay for now if the other resources are created.

Step 3 — Check Argo CD pods
kubectl get pods -n argocd

All of these to become Running:

argocd-server
argocd-repo-server
argocd-application-controller
argocd-applicationset-controller
argocd-redis
argocd-dex-server

Step 4 — Expose Argo CD using AWS LoadBalancer
Do not need the AWS Load Balancer Controller for a basic Service type=LoadBalancer.

Run to change the argocd-server service to use loadbalancer:
kubectl patch svc argocd-server -n argocd \
  -p '{"spec":{"type":"LoadBalancer"}}'

Check:
kubectl get svc argocd-server -n argocd -w

Initially we may see:
EXTERNAL-IP   <pending>

Wait until AWS provisions the load balancer.

we should eventually see something like:

NAME            TYPE           EXTERNAL-IP
argocd-server   LoadBalancer   xxx.us-east-1.elb.amazonaws.com

That EXTERNAL-IP is the Argo CD URL.

Open it:

https://xxx.us-east-1.elb.amazonaws.com

We may get a browser certificate warning because Argo CD uses HTTPS with its default certificate. That's expected.

Step 5 — Get Argo CD password

In another CloudShell tab:

kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath="{.data.password}" | base64 -d
echo

Login to the argocd front end:

Username: admin
Password: <output from above>
